🚀 INSTALLATION STEPS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: Extract Files
──────────────────────
Extract the nutritrack-pro folder to your web server directory:
  • XAMPP: C:\xampp\htdocs\
  • WAMP: C:\wamp64\www\
  • LAMP: /var/www/html/

STEP 2: Start Services
──────────────────────
Open XAMPP/WAMP Control Panel and start:
  ✓ Apache (Web Server)
  ✓ MySQL (Database)

STEP 3: Create Database
────────────────────────
1. Open browser and go to: http://localhost/phpmyadmin
2. Click "New" to create a new database
3. Database name: nutritrack_pro
4. Collation: utf8mb4_general_ci
5. Click "Create"

STEP 4: Import Database Schema
───────────────────────────────
1. Select the "nutritrack_pro" database
2. Click on "Import" tab
3. Click "Choose File" and select: database/schema.sql
4. Scroll down and click "Go"
5. Wait for success message

STEP 5: Configure Database Connection (if needed)
──────────────────────────────────────────────────
Open file: backend/config/database.php

Default settings:
  DB_HOST = 'localhost'
  DB_USER = 'root'
  DB_PASS = ''
  DB_NAME = 'nutritrack_pro'

Change only if your MySQL has different credentials.

STEP 6: Access Application
───────────────────────────
Open your web browser and navigate to:
  http://localhost/nutritrack-pro/

🔧 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problem: "Database connection failed"
Solution: 
  • Check MySQL is running in XAMPP/WAMP
  • Verify database name is "nutritrack_pro"
  • Check credentials in backend/config/database.php

Problem: "Page not found" or 404 errors
Solution:
  • Ensure folder is named exactly "nutritrack-pro"
  • Check Apache is running
  • URL should be: http://localhost/nutritrack-pro/

Problem: "Login not working"
Solution:
  • Clear browser cache and cookies
  • Check PHP sessions are enabled
  • Verify admin credentials are typed correctly

Problem: "Blank page" or "PHP errors"
Solution:
  • Check PHP error logs in XAMPP/logs/
  • Ensure PHP version is 7.4+
  • Verify all files extracted correctly
